💡 Academic DSA Explanation: Why collections.deque instead of Python list?

In a standard Python list, removing the first waiting element via list.pop(0) takes O(N) time because all subsequent $N-1$ elements must be shifted in contiguous memory. In contrast, collections.deque (Double-Ended Queue) is implemented in C as a doubly linked list of memory blocks. Both enqueue (append()) and dequeue (popleft()) are guaranteed O(1) constant time operations!

🔄 Auto-Dispatch Trigger: When any parked vehicle exits or an unreserved slot becomes available, the manager instantly inspects the waiting queue in strict FIFO order and assigns the slot to the first eligible vehicle!
